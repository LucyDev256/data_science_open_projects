## GCP Resources Required

### Compute
- Cloud SQL PostgreSQL (4 instances): db-custom-4-16384
- Cloud Composer: medium environment (4 vCPUs)
- Cloud Functions: For webhooks
- GKE (optional): For Debezium if not using managed Kafka

### Storage
- Cloud Storage: ~500GB for data staging
- BigQuery: ~2TB storage expected

### Networking
- VPC with Private Google Access
- Cloud NAT for outbound
- VPC Peering for PHI project

### APIs to Enable
- Cloud SQL Admin API
- BigQuery API
- Cloud Composer API
- Secret Manager API
- Cloud KMS API
- Pub/Sub API
- Cloud Functions API

## External Services

### Required
- Confluent Cloud (Kafka): Standard tier
- Slack (optional): For alerts
- PagerDuty (optional): For on-call

### Optional
- Looker Studio: For BI dashboards
- dbt Cloud: Alternative to self-hosted
- Monte Carlo/Datafold: Data observability

## Access Requirements

### GCP IAM Roles
- `roles/owner` (for initial setup)
- `roles/cloudsql.admin`
- `roles/bigquery.admin`
- `roles/composer.admin`
- `roles/secretmanager.admin`
- `roles/cloudkms.admin`

### Service Accounts Needed
- `debezium-sa@project.iam.gserviceaccount.com`
- `dbt-runner-sa@project.iam.gserviceaccount.com`
- `airflow-sa@project.iam.gserviceaccount.com`
- `bigquery-writer-sa@project.iam.gserviceaccount.com`

## Minimum System Requirements (Local Development)

- **OS**: macOS, Linux, or Windows with WSL2
- **RAM**: 16GB minimum, 32GB recommended
- **CPU**: 4 cores minimum
- **Disk**: 50GB free space
- **Network**: Stable internet connection (GCP access)
