# Data Science & Analytics Portfolio

Selected projects covering forecasting, segmentation, experimentation,
large-scale data processing, NLP, and analytical application development.

## Projects

| Project | Focus | Technologies |
|---|---|---|
| [Cross-Market Business Forecasting Audit](cross-market-business-forecasting-audit/) | Customer revenue forecasting, behavioural segmentation, promotion and pricing audits, customer-order SQL | Python, pandas, scikit-learn, SciPy, BigQuery SQL |
| [Milano-Cortina 2026 Dashboard](Olympics_2026/) | Live event exploration, API ingestion, filtering, and interactive analytics | Python, Streamlit, pandas, Plotly, REST APIs |
| [Nemotron Personas USA](Nemotron_Personas_USA/) | Large-scale synthetic persona exploration, NLP, clustering, and classification | Python, pandas, scikit-learn, TF-IDF |
| [Hourly Web Traffic Forecasting](prophet_time_series-forecast/) | Sparse time-series forecasting, chronological validation, and model diagnostics | Python, Prophet, BigQuery, GCP |
| [Healthcare Claims Analytics](pyspark_project/) | Distributed ETL and machine learning over synthetic healthcare data | PySpark, BigQuery, Dataproc, GCP |

## Themes across the portfolio

- reproducible data preparation and validation;
- time-aware model evaluation and leakage prevention;
- interpretable analytical baselines before unnecessary complexity;
- explicit data-grain, quality, and causal-inference limitations;
- business-facing conclusions connected to technical evidence.

Each folder contains its own documentation, setup instructions, and analytical
scope. Projects use public or synthetic data unless stated otherwise.
