# Nemotron Personas USA - Quick Start Guide

## 🚀 Getting Started in 5 Minutes

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Open the Notebook
```bash
# Using Jupyter Lab
jupyter lab nemotron_analysis.ipynb

# OR using VS Code
# Just open nemotron_analysis.ipynb in VS Code
```

### Step 3: Run All Cells
- Click "Run All" or execute cells sequentially
- The analysis will automatically:
  - Download the dataset from Hugging Face
  - Process and analyze all text features
  - Generate clusters and patterns
  - Create professional visualizations
  - Produce executive insights

## 📊 What You'll Get

### Comprehensive Analysis Including:
1. **Dataset Statistics** - Complete overview with data quality metrics
2. **Text Analysis** - Word clouds, keyword extraction, TF-IDF analysis
3. **Clustering** - K-means segmentation with visual representations
4. **Correlations** - Chi-square tests and co-occurrence analysis
5. **Predictive Models** - Random Forest with feature importance

## 🆘 Troubleshooting

### Dataset Not Loading?
```bash
pip install --upgrade datasets transformers
```

### Visualization Issues?
```bash
pip install --upgrade plotly kaleido
```

### NLTK Errors?
```python
import nltk
nltk.download('all')
```
